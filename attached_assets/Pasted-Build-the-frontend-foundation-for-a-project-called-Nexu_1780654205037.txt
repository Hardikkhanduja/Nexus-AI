Build the frontend foundation for a project called "Nexus AI" — a multi-agent AI orchestration platform.

Do NOT build any AI functionality yet. This phase is UI only.

DESIGN SYSTEM

Apply this across every component:

Theme: Premium pixel-art cyberpunk gaming aesthetic.
Inspired by: Katana ZERO, Hyper Light Drifter, synthwave pixel interfaces.

Colors:
* Background: #0B0B0E
* Primary: #00FFB3
* Secondary: #00C8FF
* Highlight: #FF4FD8
* Danger: #FF5E5E
* Success: #00FF95
* Cards: #14141A
* Borders: pixel-style glowing

Fonts:
* Press Start 2P → headings only
* IBM Plex Sans → all body text and content

Visual elements required on every screen:
* Pixelated glowing borders on all cards
* Pixel hover effects on all buttons
* Pixel-style scanline overlay on background (subtle, not distracting)
* Animated pixel particles in background (lightweight)
