Completely redesign the Nexus AI UI with a cartoonish cyberpunk style.
Think: pixel-art RPG meets Saturday morning cartoon meets futuristic 
command center. Bold, fun, chunky, colorful — but still premium and readable.

---

CARTOONISH DESIGN RULES (apply everywhere):

* Thick chunky borders on everything (3-4px minimum, not thin lines)
* Rounded corners on all cards and buttons (12-16px border radius)
* Bold drop shadows that are visible and colorful 
  (e.g. shadow-[4px_4px_0px_#00FFB3] — hard offset shadows, not blurs)
* Colors are bright and punchy, not muted
* Icons are chunky and bold, not thin outline style
* Buttons look "pressable" — have a 3D push-down effect on click
  (transform: translateY(2px) + shadow shrinks on active)
* Everything slightly oversized — generous padding, big text, chunky inputs
* Wobble or bounce animations on key elements (logo, agent icons)
* Agent icons look like cartoon character avatars, not corporate logos
* Use emoji-style decorative elements sparingly: ⚡ 🧠 🎯 ✦ ◈
* Think: if a 16-year-old gamer saw this, they would say "this is sick"

ANIMATION GUIDELINES:
* Logo: spring bounce-in on page load
* Agent pills: staggered bounce-in (one by one, 100ms delay each)
* Cards: float up from below on enter (Framer Motion)
* Buttons: scale + shadow on hover, press-down on click
* Sidebar: slide in from left with slight bounce at end
* Page transition landing → chat: 
  search bar expands + screen wipes to chat workspace
* All animations feel snappy and fun, not slow or corporate

---

GLOBAL RULES:
* Press Start 2P → logo, panel headers, badges, section labels only
* IBM Plex Sans → everything else
* Hard drop shadows everywhere (offset, not blur)
* Chunky thick borders on all interactive elements
* Bright punchy colors, never muted or pastel
* Everything has personality — nothing looks default or boring
